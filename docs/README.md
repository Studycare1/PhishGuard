# PhishGuard — GitHub Pages

Static version of PhishGuard. All data is pre-loaded as JSON.
URL detection, password check, and email analysis run **client-side** in JavaScript.

**Live:** https://YOUR_USERNAME.github.io/phishguard/

## Files
- `index.html` — Main app
- `data/*.json` — All content data
- `static/css/style.css` — Styles
- `static/js/app.js` — Main app logic
- `static/js/detector.js` — URL detector (client-side)

Built with `build_static.py` from the Python version.
