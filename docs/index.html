1. The 5 Golden Rules
  1. Har account ka alag password — Password manager use karo (Bitwarden free hai)
  2. 2FA on karo — Authenticator app (SMS nahi). Best: hardware key (YubiKey)
  3. URL check karo — Lock icon nahi, actual domain dekho
  4. OTP kabhi kisi ko mat batao — Bank, police, CEO koi bhi ho
  5. Public WiFi pe VPN — Ya cellular data use karo
2. URL Anatomy
https:// sub . domain . tld /path ?query #fragment ASLI DOMAIN = aakhri 2 parts (ya 3 for .co.in, .gov.in) ──────────────────────────────────────────────── www.instagram.com OK asli = instagram.com instagram.secure-login.xyz BAD asli = secure-login.xyz login.paypal.com OK asli = paypal.com paypal-verify.tk BAD .tk = free phishing TLD google.com@evil.com BAD opens evil.com CHECK ORDER (right to left): 1. TLD (.com, .gov.in, .tk?) 2. Registered domain (paypal vs paypa1) 3. Subdomains (brand as subdomain?) 4. Path (login? verify? secure?) 5. Query (?redirect=http://evil.com)
3. Red Flag Checklist
  • Urgency — "24 hours", "immediate action", "act now"
  • Threat — "account blocked", "legal action", "arrest"
  • Generic greeting — "Dear Customer" (naam nahi)
  • Sender domain — thoda alag (amaz0n, paypa1, bank-secure)
  • Link mismatch — text different from actual URL
  • OTP/password/PIN request — never share
  • Unexpected attachment — .exe, .zip, .scr, .pdf.exe
  • Reply-To different — from display name
  • Too-good-to-be-true — free iPhone, ₹5000/day
  • Emotional appeal — fear, love, excitement, greed
  • Grammar/spelling — ab AI era me nahi (perfect grammar bhi red flag)
  • Login through email — company app use karo, email link nahi
4. If You Get Phished
  1. Turant password change — compromised account ka
  2. 2FA enable — pehle nahi tha to ab karo
  3. Bank ko call — agar financial info diya (24 hrs critical)
  4. Report karo — cybercrime.gov.in, helpline 1930 (India)
  5. Friends ko alert — account se spam mat jaye
  6. Have I Been Pwned — haveibeenpwned.com check karo
  7. Sessions revoke — Google/Microsoft security settings me
  8. Bank/credit card freeze — agar card details gaye
  9. Evidence preserve — screenshots, email headers save karo
  10. Monitor karo — next 30 days unusual activity check
5. Password Security
Strong Password Rules:
  • 12+ characters (16+ for critical accounts)
  • Passphrase better — 4 random words
  • Har account ka alag
  • Kabhi dictionary word based nahi
  • Kabhi personal info (DOB, name) nahi
NEVER:
  • 123456, password, qwerty, admin
  • P@ssw0rd type simple substitutions
  • Same password multiple sites pe
  • Browser me save (less secure than manager)
  • Email/notes me plain text
6. 2FA Guide
2FA Types (safest to weakest):
  1. Hardware key (YubiKey) — phishing-proof, domain-bound. Best.
  2. Passkey (FIDO2) — biometric + crypto. Phishing-proof.
  3. Authenticator app (Google Auth, Authy, Aegis) — very good
  4. Push notification — good but MFA fatigue risk
  5. SMS OTP — weak (SIM swap vulnerable)
  6. Email OTP — weakest

Recommendation: Hardware key + backup key. Ya authenticator app + backup codes. SMS sirf fallback.

7. Email Headers
Important Headers:
  • From: Display name ≠ actual address (spoofable)
  • Reply-To: Alag ho sakta — check karo
  • Return-Path: Real envelope sender
  • Received: Path trace (top-down read karo)
  • SPF: Pass/Fail/SoftFail
  • DKIM: Signature valid?
  • DMARC: Policy applied?
  • Message-ID: Unique per email

Gmail: 3-dot menu → "Show original". Outlook: File → Properties.

8. Mobile Safety
  • Unknown SMS links pe click mat karo
  • Bank app use karo — SMS se login nahi
  • App permissions audit (contacts, SMS, camera)
  • Play Store/App Store ke bahar se APK install mat karo
  • Public charging — USB data lines se malware (juice jacking)
  • Screen lock on (PIN + biometric)
  • Find My Device enable
  • Public WiFi pe VPN
  • Auto-update on rakho (OS + apps)
9. Public WiFi Safety
  • Never banking on public WiFi (VPN ke bina)
  • HTTPS-only browsing
  • VPN pehle connect karo, phir kaam
  • File sharing off karo
  • Auto-connect disable
  • Network forget karo use ke baad
  • Starbucks/airport official WiFi naam confirm karo
  • Evil twin se bachne ke liye login page skip karo
10. Banking Safety
  • Bank app use karo (SMS/web se better)
  • Transaction alerts enable karo
  • Card ke liye separate low-limit account
  • UPI PIN kabhi share mat karo
  • Virtual card numbers (one-time) use karo
  • Bank ka official number save karo
  • Regular statement check karo
  • KYC sirf bank branch/app me
  • Account nominee add karo
11. AI-Era Defense
  • Family code word banao — AI voice clone se bachne ke liye
  • Out-of-band verification — sensitive requests pe callback
  • Video call me challenge — random question poochho
  • Reverse video call — unko call karo (deepfake nahi hoga)
  • AI agents ke permissions — least privilege
  • Passkeys use karo — passwordless phishing-proof
  • AI content skeptically — perfect grammar ≠ real
  • Hardware wallet — crypto ke liye
  • Multimodal verify — multiple channels confirm karo
12. Incident Response
IMMEDIATE (0-1 hr):
  • Account password change
  • 2FA enable
  • Bank call (financial info)
  • Card freeze
SHORT-TERM (1-24 hr):
  • Report cybercrime.gov.in / 1930
  • Friends/family alert
  • Sessions revoke all devices
  • Bank transactions monitor
LONG-TERM (1-30 days):
  • Credit report check (CIBIL)
  • Password reset all accounts
  • Bank account statement review
  • Identity theft monitoring

2024
Arup Deepfake Video Heist
$25M Loss · Hong Kong

Hong Kong engineering firm Arup ke employee ko multi-person Zoom call aayi. 'CFO' aur 3 'colleagues' real dikhe — actually sab AI deepfake the. Meeting me urgent confidential wire transfer bola. Employee ne 15 transactions me $25M (~₹200 crore) transfer kiye. Baad me real CFO ne call karke deny kiya.

🎯 Attack: Multi-person deepfake video + social engineering
💥 Impact: $25M irrecoverable. First documented large-scale AI heist.
🎓 Lesson: Video calls bhi trustworthy nahi. Code word + out-of-band callback mandatory.
🏷️ Tags: #Deepfake #AI #BEC #Zoom
2020
SolarWinds Supply Chain Attack
18K+ Orgs · APT29

Russian APT29 (SVR) ne SolarWinds Orion software ke build process compromise kiya. 'SUNBURST' backdoor inject kiya — digitally signed update me. Automatic update se 18,000+ organizations affected — US Treasury, DHS, Fortune 500, cybersecurity firms. Attackers 9+ months undetected the. Attack chain: build → distribute → activate → move laterally.

🎯 Attack: Build pipeline compromise + signed malicious update
💥 Impact: 18K+ orgs, US government agencies, 9+ months dwell time
🎓 Lesson: Trusted updates verify karo. Software supply chain critical infrastructure hai.
🏷️ Tags: #SupplyChain #APT29 #SUNBURST
2020
Twitter Internal Hack
130+ Accounts · $118K Bitcoin

Teen hackers (17-22 saal) ne Twitter employees ko spear-phish kiya — phone call + fake VPN page. Employees ne credentials daale. Internal tools access mile — jisse wo arbitrary accounts compromise kar sakte the. Obama, Musk, Apple, Bill Gates ke accounts se Bitcoin scam tweets bheje. $118,000 Bitcoin collected. FBI investigation me mastermind Graham Ivan Clark arrested.

🎯 Attack: Spear phishing + phone call + fake VPN page
💥 Impact: 130+ high-profile accounts, trust damage, SEC investigation
🎓 Lesson: Internal tools pe MFA mandatory. Employees = biggest vulnerability.
🏷️ Tags: #Twitter #SpearPhishing #Bitcoin
2016
Google + Facebook $100M BEC
$100M Loss · Global

Lithuanian hacker Evaldas Rimasauskas ne fake 'Quanta Computer' company banai — Taiwan me actually exist karti hai. Fake invoices, letterheads, tax documents sab banaye. Google + Facebook ko $100M ke fake invoices bheje (2 saal me). Bank accounts Cyprus, Latvia, Hungary me. 2019 me Rimasauskas ne guilty plead kiya — 5 saal jail + $49.7M forfeiture.

🎯 Attack: Vendor impersonation + fake invoices + bank account hopping
💥 Impact: $100M transfer, 2-year ongoing campaign
🎓 Lesson: Vendor verification process critical. Bank changes pe callback mandatory.
🏷️ Tags: #BEC #Vendor #Invoice #Quanta
2015
Ubiquiti Networks Pretexting
$46.7M Loss · Pretexting

Ubiquiti Networks ke finance team ko fake CEO + lawyer pretexting emails aaye. Attacker ne khud ko legal counsel + finance head bola — believable story ke saath. 4 wire transfers Hong Kong bank accounts me. Total $46.7M. FBI ne $8.5M recover kiye. Case ne corporate wire transfer protocols industry-wide change kiye.

🎯 Attack: Pretexting + executive impersonation + wire transfer
💥 Impact: $46.7M loss, only $8.5M recovered
🎓 Lesson: Seniority claim verify karo. Wire transfers pe dual approval mandatory.
🏷️ Tags: #Pretexting #BEC #WireFraud
2022
Uber MFA Fatigue Attack
Full Breach · Social Engineering

Lapsus$ teenager group ne Uber contractor ko MFA fatigue attack. 100+ push notifications raat 2 baje. Victim ne eventually 'Approve' daba diya. Attacker ne internal systems access kiye — Slack, HackerOne, financial dashboards, email. Screenshots leak kiye. Similar attack Cisco pe bhi hua. Both companies ne MFA improvements announce kiye.

🎯 Attack: MFA push bombing + WhatsApp social engineering
💥 Impact: Full internal access, sensitive data exposure
🎓 Lesson: Number matching MFA zaroori. Push limits + password change on flood.
🏷️ Tags: #MFAFatigue #Uber #Lapsus
2023
MOVEit Mass Exploitation
90M+ Records · Cl0p

MOVEit Transfer (file-sharing software) me SQL injection zero-day. Cl0p ransomware group ne mass exploitation ki. 2,600+ organizations affected — banks, government agencies, healthcare, education. 90M+ individuals' data stolen. Ransom demanded but no encryption — pure data extortion. BBC, British Airways, Shell, US Dept of Energy sab affected.

🎯 Attack: Zero-day SQLi + mass automated exploitation
💥 Impact: 2,600+ orgs, 90M+ records, ongoing extortion
🎓 Lesson: Third-party software assessment. Data retention = liability.
🏷️ Tags: #MOVEit #Cl0p #ZeroDay
2023
3CX Supply Chain Trojan
600K+ Companies · Lazarus

3CX VoIP software (600,000+ companies use karti) ke Windows + Mac builds me malware inject hua. North Korean APT Lazarus ne supply chain compromise kiya. Malicious update deploy hui. Attackers ne 3CX customers se aage 'Trading Technologies' (another vendor) ko bhi target kiya. Double supply chain attack — crypto companies aur BPOs primarily affected.

🎯 Attack: Two-stage supply chain, code signing abuse
💥 Impact: 600K+ companies potentially exposed
🎓 Lesson: Build pipeline security. Code signing ≠ malware-free.
🏷️ Tags: #3CX #Lazarus #SupplyChain
2023
OAuth Consent BEC Wave
Enterprise-wide · Microsoft/Google

Attackers ne 'Adobe Sign', 'DocuSign', 'Zoom' jaise fake OAuth apps banaye. Microsoft 365 aur Google Workspace environments me deploy kiye. Employees ne 'Allow' kiya. Full mailbox access mila — password nahi chahiye. Password change bhi kaam nahi aaya — refresh token valid tha. Attackers ne internal emails padhke wire transfers convince kiye. Microsoft ne 'verified publisher' introduce kiya.

🎯 Attack: OAuth consent phishing + refresh token abuse
💥 Impact: Widespread enterprise BEC, password reset ineffective
🎓 Lesson: OAuth permissions review. Token revocation bhi karo.
🏷️ Tags: #OAuth #BEC #Microsoft365
2014
World Cup Brazil Evil Twin WiFi
Thousands Affected · Brazil

FIFA World Cup ke dauraan attackers ne fake WiFi hotspots setup kiye. 'FIFA_Free_WiFi', 'Stadium_Official', 'WorldCup_2024' jaise naam. Hazaaron international tourists ne connect kiye. Attackers ne traffic sniff kiya — credentials, credit cards, social media sab capture. Similar attacks Olympics, conferences, airports me hote hain.

🎯 Attack: Evil twin WiFi + traffic interception
💥 Impact: Thousands of tourists, mass credential theft
🎓 Lesson: Public WiFi pe VPN mandatory. Sensitive kaam avoid.
🏷️ Tags: #EvilTwin #WiFi #WorldCup
2007
Banca de los Andes DNS Hijack
First Pharming · Mexico

Mexican bank Banca de los Andes ka DNS infrastructure compromise hua. Customers 'banca.com' type karte the — URL bilkul sahi dikhta tha — par nakli site khulti thi. Attacker ne credentials capture kiye. Loss $100k+. Ye pehla documented large-scale pharming attack tha. Case ne industry-wide DNSSEC adoption accelerate kiya.

🎯 Attack: DNS hijacking + URL spoofing
💥 Impact: $100k+ loss, no URL forensics possible
🎓 Lesson: DNSSEC deployment. Certificate warnings never ignore.
🏷️ Tags: #Pharming #DNS #Mexico
2024
Cornell Morris II Prompt Worm
AI Research · Proactive

Cornell Tech researchers ne 'Morris II' prompt worm demonstrate kiya — 1988 ke Morris worm ka AI version. Malicious prompt jo AI assistants (ChatGPT, Gemini, Claude) ke beech self-replicate karta. Email + messages via indirect prompt injection. Test environment me successful. AI ecosystem me worm attack possible ka proof. Named as 'first generative AI worm'.

🎯 Attack: AI-to-AI worm via prompt injection
💥 Impact: Research demonstration, no production attack yet
🎓 Lesson: AI agents = new attack surface. Zero trust AI mandatory.
🏷️ Tags: #AIWorm #PromptInjection #Research
